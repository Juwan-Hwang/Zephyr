feat(desktop)：侧栏加文字并可展开收起，文字对比度达到 WCAG AA，新增选择卡片

侧栏
- 保留原来的图标，每个图标旁边加短名字（中日韩两个字，其他语言侧栏
  加宽到 192 px，名字不截断）。
- 能展开和收起，但不加任何按钮：拖侧栏右边缘（双击切换）、macOS 上
  ⌃⌘S、Windows 和 Linux 上 Ctrl+B、右键侧栏的一项菜单；窗口窄于
  860 px 时自动收起，这时展开会盖在内容上面，点页面或按 Esc 收回。
  宽窗口里的选择会记住。
- 收起和展开时图标位置不动，只有宽度变化；名字只在被截断时才有悬停提示。
- 选中项改成平铺的浅底色，不再像浮起的盒子；深色模式下没选中的项提亮。

对比度
- 浅色模式三级文字 0.4 → 0.64，muted #71717a → #5b5b65；深色模式三级
  0.4 → 0.52，muted → #8e8e98。
- 主按钮蓝底 #007AFF → #0062D6，浅底上的蓝字 #0058C2，深色模式蓝字
  #4DA3FF、红字 #F87171。品牌蓝仍用在图标、滑块和选中描边上。

选择卡片
- 新增通用的 .choice-card 组件。4 个及以上选项的单选用它，2–3 个仍用
  分段控件。订阅编辑弹窗的「自动更新」（4 个预设）改用它。

节点卡片
- 最小宽度 180 → 200 px。
- 只在悬停时出现的重新测试按钮，平时不再占 20 px，副标题不会被截断。
