新组件：选择卡片

写进了 styles.css，类名 .choice-grid（容器，--choice-cols 调列数）和 .choice-card（每项一个标题加一行说明）。选中时 accent 描边、浅色底加 3px 辉光环；另有悬停、键盘焦点、禁用和深色模式，只用现有设计变量。

  • 为什么适合：几个选项互斥，而且光看名字不知道该选哪个，每项都要一行说明。标签自己就说明白的（比如订阅的自动更新间隔）继续用分段控件。
  • 测速地址弹窗：4 个常用地址，每项一行域名，选之前就知道会请求哪里。
  • 导出日志的「导出内容」：应用 / 核心 / 全部，每项一行说明什么问题该选它，用户不用先懂两种日志的区别。
  • 外观里的「主页模式」：极简 / 控制台，每项一行说明首页会显示什么。
